# Radiator / Baseboard Vent

Deflectors and covers for household radiators and baseboard heat: a scoop deflector
that redirects a register's airflow into the room, a louvered baseboard cover panel,
and an L-profile corner deflector. Everything is parametric to the register or
baseboard channel you measure, and each part prints flat as a single louvered panel.

## Modes

- **Register Scoop Deflector** — a base plate that sits over a floor/wall register
  plus a raked louvered face that lifts at the set angle to throw conditioned air out
  into the room instead of straight up a wall or under furniture.
- **Louvered Baseboard Cover** — a flat louvered front cover panel with horizontal
  vent slots and optional screw tabs, to replace a dented or missing metal cover.
- **L-Profile Corner Deflector** — a mounting flange and a louvered deflection vane
  meeting at a fold, to steer air around a corner or away from a wall register.

## Dimensions

These are project-internal profiles (no external dimensional standard), sized to
common residential registers (roughly 4x10" to 6x12") and baseboard fin covers
(roughly 175–230 mm tall). Set width, height, thickness, and louver count to fit your
opening.

## Key parameters

| Parameter | Meaning |
|-----------|---------|
| Width | panel / register width |
| Height / Scoop Depth | cover height, scoop face length, or vane length |
| Panel Thickness | wall thickness (2.0–6.0 mm) |
| Louver Slot Count | number of vent slots |
| Deflection Angle | how steeply the scoop / vane rises (10–60°) |
| Mounting Tabs | screw ears at the top corners |

## Printing notes

The scoop deflector prints base-down; the raked face is self-supporting up to about
60°. The flat baseboard cover and its louvers print without supports. These are the
simplest parts in the plumbing/HVAC set — a good first print. PLA is fine for
low-temperature baseboard and register air.

# Ventila de Radiador / Zocalo

Deflectores y cubiertas para radiadores y calefaccion de zocalo del hogar: un
deflector tipo pala que redirige el flujo de una rejilla hacia la habitacion, un panel
de cubierta de zocalo con rejillas y un deflector de esquina en perfil L. Todo es
parametrico a la rejilla o canal de zocalo que midas, y cada pieza se imprime plana
como un solo panel con rejillas.

## Modos

- **Deflector Tipo Pala para Rejilla** — una placa base sobre una rejilla de
  piso/pared mas una cara con rejillas inclinada que se eleva en el angulo ajustado
  para lanzar el aire acondicionado a la habitacion en lugar de directo a una pared o
  bajo los muebles.
- **Cubierta de Zocalo con Rejillas** — un panel de cubierta frontal plano con ranuras
  de ventilacion horizontales y pestanas de tornillo opcionales, para reemplazar una
  cubierta metalica abollada o faltante.
- **Deflector de Esquina Perfil L** — una brida de montaje y una aleta de deflexion
  con rejillas que se encuentran en un pliegue, para dirigir el aire alrededor de una
  esquina o lejos de una rejilla de pared.

## Dimensiones

Estos son perfiles internos del proyecto (sin estandar dimensional externo),
dimensionados a rejillas residenciales comunes (aprox. 4x10" a 6x12") y cubiertas de
aletas de zocalo (aprox. 175–230 mm de alto). Ajusta ancho, altura, espesor y numero
de rejillas para tu abertura.

## Parametros clave

| Parametro | Significado |
|-----------|-------------|
| Ancho | ancho del panel / rejilla |
| Altura / Profundidad de Pala | altura de cubierta, largo de cara de pala o aleta |
| Espesor del Panel | espesor de pared (2.0–6.0 mm) |
| Numero de Rejillas | numero de ranuras de ventilacion |
| Angulo de Deflexion | que tan pronunciado se eleva la pala / aleta (10–60°) |
| Pestanas de Montaje | orejas de tornillo en las esquinas superiores |

## Notas de impresion

El deflector de pala se imprime con la base hacia abajo; la cara inclinada se
auto-soporta hasta cerca de 60°. La cubierta plana de zocalo y sus rejillas se
imprimen sin soportes. Estas son las piezas mas simples del conjunto de plomeria/HVAC
— una buena primera impresion. PLA sirve para aire de zocalo y rejilla de baja
temperatura.
