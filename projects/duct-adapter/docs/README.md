# Duct / Vent Register Adapter

Parametric HVAC transition fittings that bridge the size and shape mismatches every
residential duct run hits. Round-to-round reducers, rectangular register boots, and
rectangular-to-rectangular reducers, all built on real US sheet-metal sizing and
printed as a single watertight hollow duct.

## Modes

- **Round-to-Round Reducer** — concentric round reducer from a larger trunk to a
  smaller take-off, with a straight collar at each end for a slip fit.
- **Rectangular Register Boot** — a straight boot lofting a rectangular register
  opening down to a round duct throat, with an optional mounting flange.
- **Rectangular-to-Rectangular Reducer** — a reducer between two register sizes,
  keeping a rounded-corner cross-section throughout.

## Real dimensions

- Round duct nominal IDs: 4" = 101.6 mm, 5" = 127.0 mm, 6" = 152.4 mm.
- Rectangular register openings: 4x10, 4x12, 6x10, 6x12 inches
  (101.6x254.0, 101.6x304.8, 152.4x254.0, 152.4x304.8 mm).

## Key parameters

| Parameter | Meaning |
|-----------|---------|
| Round Port A / B | round sizes for the reducer / boot throat |
| Rectangular Register Opening | register size (4x10 … 6x12) |
| Transition Length | axial length of the tapered section |
| End Collar Length | straight slip-fit section at each end |
| Wall Thickness | duct wall (1.0–4.0 mm) |
| Rectangular Corner Radius | fillet on rectangular openings |
| Register Mounting Flange | flat perimeter flange on the rectangular face |

## Printing notes

Print collar-end down. The duct is a single closed shell with annular end rims, so
no supports are needed inside the lumen for shallow transitions. For steep round-to-
rectangular boots, a light brim helps the wide rectangular flange stay flat. PLA or
PETG at 2–3 perimeters is airtight enough for low-pressure residential supply air.

# Adaptador de Ducto / Rejilla de Ventilacion

Accesorios de transicion HVAC parametricos que resuelven los desajustes de tamano y
forma de cualquier instalacion de ductos residencial. Reductores redondo a redondo,
botas de rejilla rectangular y reductores rectangular a rectangular, basados en
medidas reales de lamina US e impresos como un solo ducto hueco hermetico.

## Modos

- **Reductor Redondo a Redondo** — reductor redondo concentrico de un tronco mayor a
  una toma menor, con un collar recto en cada extremo para ajuste deslizante.
- **Bota de Rejilla Rectangular** — una bota recta que transiciona una abertura de
  rejilla rectangular a una garganta de ducto redondo, con brida de montaje opcional.
- **Reductor Rectangular a Rectangular** — un reductor entre dos tamanos de rejilla,
  manteniendo una seccion de esquinas redondeadas.

## Dimensiones reales

- Diametros interiores redondos nominales: 4" = 101.6 mm, 5" = 127.0 mm, 6" = 152.4 mm.
- Aberturas de rejilla rectangulares: 4x10, 4x12, 6x10, 6x12 pulgadas.

## Parametros clave

| Parametro | Significado |
|-----------|-------------|
| Puerto Redondo A / B | tamanos redondos para el reductor / garganta de la bota |
| Abertura de Rejilla Rectangular | tamano de rejilla (4x10 … 6x12) |
| Longitud de Transicion | longitud axial de la seccion conica |
| Longitud del Collar | seccion recta de ajuste deslizante en cada extremo |
| Espesor de Pared | pared del ducto (1.0–4.0 mm) |
| Radio de Esquina Rectangular | redondeo en aberturas rectangulares |
| Brida de Montaje de Rejilla | brida perimetral plana en la cara rectangular |

## Notas de impresion

Imprime con el extremo del collar hacia abajo. El ducto es una sola cascara cerrada
con bordes anulares, por lo que no requiere soportes internos en transiciones poco
pronunciadas. Para botas redondo-a-rectangular pronunciadas, un borde ligero ayuda a
que la brida rectangular ancha quede plana. PLA o PETG con 2–3 perimetros es
suficientemente hermetico para aire de suministro residencial de baja presion.
