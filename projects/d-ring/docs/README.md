# D-Ring

A 3D-printed **the flat-bottomed loop that anchors straps and webbing on bags, packs, and overalls** — generated with **CadQuery** (B-Rep). The rigid hard good Fashion
Cabinet's `d-ring` notion places and bridges to **here** for its geometry.

Part of the **Yantra4D Hyperobjects Commons** (a Fashion Cabinet FC-200 co-created finding).
Official visualizer and configurator: [Yantra4D](https://app.yantra4d.com).

## Modes

| Mode | Part |
| :--- | :--- |
| **D-Ring** | `d_ring` |
| **Square Ring** | `square` |

## Hyperobject Profile

- **Domain:** wearable
- **CDG interfaces:** Webbing Bar Edge (`flange`) and Bow Loop (`snap`) — the flange is the sewn/set
  edge the Fashion Cabinet dimensional handshake couples to.

## Fabrication notes

Built from safe primitives (cylinders, boxes, boolean cuts, light fillets) — watertight,
prints small and rigid. `CERN-OHL-W-2.0`.
