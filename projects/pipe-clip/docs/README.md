# Pipe Insulation Clip / Standoff

Pipe supports for copper and PEX runs: a C-shaped snap clip that clicks onto the pipe,
a saddle standoff that holds the pipe off the wall on a screw post, and a two-ear band
clamp that fully surrounds the pipe. Bores are sized to real copper and PEX outside
diameters so the grip matches the pipe you actually have.

## Modes

- **C-Snap Clip** — a C-shaped snap clip on a flat screw base. The mouth is opened
  narrower than the pipe diameter so the pipe clicks in and is retained.
- **Saddle Standoff** — a half-round saddle cradle raised on a screw post so the pipe
  stands off the wall by an adjustable distance, for clearance and to reduce sweating
  contact.
- **Two-Ear Band Clamp** — a full ring that surrounds the pipe with a screw ear on
  each side, for a firm anchored clamp where a snap clip is not enough.

## Real dimensions

- Copper 1/2" OD = 0.625" = 15.875 mm.
- Copper 3/4" OD = 0.875" = 22.225 mm.
- Copper 1"  OD = 1.125" = 28.575 mm.
- PEX 1/2" OD = 15.875 mm; PEX 3/4" OD = 22.225 mm.

## Key parameters

| Parameter | Meaning |
|-----------|---------|
| Pipe Size | copper or PEX 1/2"–1" |
| Bore Clearance | radial gap over the pipe OD (0.1–0.7 mm) |
| Snap Mouth Opening | mouth width as a fraction of OD (snap clip only) |
| Wall Thickness | clip wall around the bore |
| Clip Length Along Pipe | how much of the pipe length the clip wraps |
| Standoff Height | how far the saddle holds the pipe off the wall |

## Printing notes

Print the C-snap clip mouth-up so the jaw prints without supports and keeps its
spring. For a firmer snap, lower the mouth opening toward 0.55; for insulated pipe,
raise the bore clearance. PETG gives a better living-snap than brittle PLA. The saddle
standoff and band clamp print base-down.

# Clip / Separador de Tuberia

Soportes de tuberia para lineas de cobre y PEX: un clip de presion en C que se encaja
en la tuberia, un separador de silla que sostiene la tuberia lejos de la pared sobre
un poste con tornillos y una abrazadera de banda de dos orejas que rodea por completo
la tuberia. Los barrenos se dimensionan a diametros exteriores reales de cobre y PEX
para que el agarre coincida con tu tuberia.

## Modos

- **Clip de Presion en C** — un clip en C sobre una base plana con tornillos. La boca
  se abre mas angosta que el diametro para que la tuberia entre a presion y quede
  retenida.
- **Separador de Silla** — una silla de media caña elevada sobre un poste con
  tornillos para que la tuberia quede separada de la pared una distancia ajustable,
  para holgura y para reducir el contacto de condensacion.
- **Abrazadera de Banda de Dos Orejas** — un anillo completo que rodea la tuberia con
  una oreja de tornillo a cada lado, para un anclaje firme donde un clip de presion no
  basta.

## Dimensiones reales

- Cobre 1/2" OD = 0.625" = 15.875 mm.
- Cobre 3/4" OD = 0.875" = 22.225 mm.
- Cobre 1"  OD = 1.125" = 28.575 mm.
- PEX 1/2" OD = 15.875 mm; PEX 3/4" OD = 22.225 mm.

## Parametros clave

| Parametro | Significado |
|-----------|-------------|
| Tamano de Tuberia | cobre o PEX 1/2"–1" |
| Holgura del Barreno | espacio radial sobre el OD (0.1–0.7 mm) |
| Apertura de la Boca de Presion | ancho de boca como fraccion del OD (solo clip C) |
| Espesor de Pared | pared del clip alrededor del barreno |
| Largo del Clip a lo Largo de la Tuberia | cuanto abarca el clip |
| Altura del Separador | cuanto separa la silla la tuberia de la pared |

## Notas de impresion

Imprime el clip en C con la boca hacia arriba para que la mordaza salga sin soportes y
conserve su resorte. Para un agarre mas firme, baja la apertura hacia 0.55; para
tuberia aislada, sube la holgura del barreno. El PETG da mejor resorte que el PLA
quebradizo. El separador de silla y la abrazadera se imprimen con la base hacia abajo.
