# P-Trap / Drain Fitting

Under-sink tubular drainage parts built to real US slip-joint sizing: a P-trap
U-bend, a quarter-bend trap arm, and a straight tailpiece extension. Every part
carries slip-joint sockets so it mates with standard tubular drain tube using the
usual slip nut and beveled washer.

## Modes

- **P-Trap U-Bend** — the water-seal trap under a sink: two vertical legs joined by a
  180° bottom bend, slip socket on top of each leg.
- **Quarter-Bend Trap Arm** — a straight run into a 90° elbow that carries the trap
  outlet across to the wall drain stub; slip socket inlet, plain spigot outlet.
- **Straight Tailpiece Extension** — a straight vertical extension with a slip socket
  on top and a plain outlet below, to drop a sink strainer down to the trap.

## Real dimensions

- 1-1/4" tube OD = 1.66" = 42.16 mm.
- 1-1/2" tube OD = 1.90" = 48.26 mm.

The slip socket is bored to (tube OD + clearance) so the mating tube slides in and
butts an internal shoulder; the slip nut threads onto the outside in service.

## Key parameters

| Parameter | Meaning |
|-----------|---------|
| Slip-Joint Tube Size | 1-1/4" or 1-1/2" |
| Slip-Fit Clearance | radial gap over the tube OD (0.1–0.8 mm) |
| Socket Depth | how far the mating tube seats |
| Pipe Wall Thickness | wall around the flow bore |
| Centerline Bend Radius | radius of trap / elbow bends (auto-floored to clear the tube) |
| Leg / Run Length | straight length of legs / run / body |

## Printing notes

Print the P-trap belly-down with supports under the 180° bend, or split at a leg for
support-free halves you glue. PETG or ASA is preferred over PLA for hot-water drain
service. The bend radius is automatically floored so the swept walls never self-
intersect at extreme settings.

# Sifon P / Accesorio de Drenaje

Piezas de drenaje tubular bajo el fregadero con medidas reales de junta deslizante
US: una curva en U de sifon P, un brazo de trampa de cuarto de vuelta y una extension
de cola recta. Cada pieza lleva bocas de junta deslizante compatibles con tuerca
deslizante y arandela biselada estandar.

## Modos

- **Curva en U del Sifon P** — la trampa de sello de agua bajo un fregadero: dos
  piernas verticales unidas por una curva inferior de 180°, boca deslizante arriba de
  cada pierna.
- **Brazo de Trampa de Cuarto de Vuelta** — un tramo recto a un codo de 90° que lleva
  la salida de la trampa hacia el tocon de drenaje de la pared; entrada con boca
  deslizante, salida de espiga plana.
- **Extension de Cola Recta** — una extension vertical recta con boca deslizante
  arriba y salida plana abajo, para bajar el colador del fregadero hasta la trampa.

## Dimensiones reales

- Tubo de 1-1/4" OD = 1.66" = 42.16 mm.
- Tubo de 1-1/2" OD = 1.90" = 48.26 mm.

La boca deslizante se barrena a (OD del tubo + holgura) para que el tubo entre y tope
con un hombro interno; la tuerca deslizante enrosca por fuera en servicio.

## Parametros clave

| Parametro | Significado |
|-----------|-------------|
| Tamano de Tubo de Junta Deslizante | 1-1/4" o 1-1/2" |
| Holgura de Ajuste Deslizante | espacio radial sobre el OD (0.1–0.8 mm) |
| Profundidad de la Boca | cuanto entra el tubo |
| Espesor de Pared del Tubo | pared alrededor del barreno |
| Radio de Curva en el Eje | radio de curvas (con piso automatico para librar el tubo) |
| Longitud de Pierna / Tramo | largo recto de piernas / tramo / cuerpo |

## Notas de impresion

Imprime el sifon con la panza hacia abajo con soportes bajo la curva de 180°, o
divide en una pierna para mitades sin soporte que se pegan. Se prefiere PETG o ASA
sobre PLA para servicio de drenaje con agua caliente. El radio de curva tiene piso
automatico para que las paredes barridas no se auto-intersequen en ajustes extremos.
