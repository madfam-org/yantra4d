# Suspender Clip

A 3D-printed **the clasp clip of suspenders and braces — the metal clip made printable** — generated with **CadQuery** (B-Rep). The rigid hard good Fashion
Cabinet's `suspender-clip` notion places and bridges to **here** for its geometry.

Part of the **Yantra4D Hyperobjects Commons** (a Fashion Cabinet FC-200 co-created finding).
Official visualizer and configurator: [Yantra4D](https://app.yantra4d.com).

## Modes

| Mode | Part |
| :--- | :--- |
| **Clip** | `clip` |
| **Plate (no teeth)** | `plate` |

## Hyperobject Profile

- **Domain:** wearable
- **CDG interfaces:** Webbing Slot (`flange`) and Grip Jaw (`snap`) — the flange is the sewn/set
  edge the Fashion Cabinet dimensional handshake couples to.

## Fabrication notes

Built from safe primitives (cylinders, boxes, boolean cuts, light fillets) — watertight,
prints small and rigid. `CERN-OHL-W-2.0`.
