# Sentinel Soft Gripper

The **Sentinel Soft Gripper** is a multi-material predictive hyperobject designed to showcase the integration of generative kinematics and dynamic topological optimization. 

## Design Characteristics
- **Bones:** Rigid `housing` and `skeleton` matrices rendered in standard thermoplastics (PETG/ABS).
- **Flexures & Friction Pads:** Rendered in low-hardness compliants (TPU). The soft hinge `flexures` are dynamically parameterized to bend seamlessly inward when the actuator is pulled without causing delamination fatigue.

## Usage
1. Open inside Yantra4D.
2. Select parameters including **Total Fingers** (2, 3, or 4).
3. Use the **Kinematic Extrusion** timeline to verify flexure bending geometries.
4. Execute **AI Topo Optimization** to algorithmically shrink the flexure thickness until the optimal strain balance is achieved based on simulated B-Rep bounds.
