# Faucet Aerator / Cache

A faucet-aerator housing that screws onto a standard tap, a matching screw-together
stash capsule (the cache), and knurled bodies you can grip by hand. The family shares
real aerator thread standards so parts interchange and also mate with the companion
`hose-adapter` cartridge.

## Modes

- **Aerator Housing** — the threaded cap. In female mode it screws down over a male
  tap spout to hold a screen; in male mode it presents an external spigot thread.
- **Cache Cup** — a closed-bottom stash cup with an external thread at its mouth so
  the lid screws on. The cavity opens only to the top face — no sealed void.
- **Cache Lid** — a shallow knurled cap with an internal thread that screws onto the
  cup mouth to seal the stash.

## Real dimensions

- M22 x 1 — the common **male** aerator thread (22.0 mm major, 1.0 mm pitch).
- M24 x 1 — the common **female** aerator thread (24.0 mm major, 1.0 mm pitch).

Threads are printed as helical ribs fused into the wall; clearance is subtracted
(male) or added (female) so printed threads mate without a tap.

## Key parameters

| Parameter | Meaning |
|-----------|---------|
| Aerator Thread Standard | M22 or M24 |
| Housing Thread Direction | female cap or male spigot |
| Thread Fit Clearance | per-side slop on printed threads (0.1–0.7 mm) |
| Wall Thickness | wall around the bore / cavity |
| Housing Height | overall housing height |
| Cache Cavity Depth | inner stash depth (cup mode) |
| Knurled Grip | axial grip flutes |

## Printing notes

Print threaded parts axis-vertical with no supports; the M22/M24 threads print
cleanly at 0.15–0.20 mm layers. Start at 0.35 mm clearance and reduce for a tighter
fit. Because the thread ribs are positive material (not cut grooves), each part comes
off the bed as a single watertight body.

# Aireador de Grifo / Cache

Una carcasa de aireador de grifo que se enrosca en una llave estandar, una capsula de
guardado que se enrosca a juego (el cache) y cuerpos moleteados para agarrar con la
mano. La familia comparte estandares reales de rosca de aireador; las piezas son
intercambiables y encajan con el cartucho complementario `hose-adapter`.

## Modos

- **Carcasa de Aireador** — la tapa roscada. En modo hembra se enrosca sobre una
  boquilla macho para sostener una malla; en modo macho presenta una espiga externa.
- **Vaso del Cache** — un vaso de guardado con fondo cerrado y rosca externa en la
  boca para que la tapa enrosque. La cavidad abre solo a la cara superior — sin hueco
  sellado.
- **Tapa del Cache** — una tapa baja moleteada con rosca interna que enrosca en la
  boca del vaso para sellar el guardado.

## Dimensiones reales

- M22 x 1 — la rosca **macho** comun de aireador (22.0 mm mayor, 1.0 mm paso).
- M24 x 1 — la rosca **hembra** comun de aireador (24.0 mm mayor, 1.0 mm paso).

Las roscas se imprimen como nervaduras helicoidales fusionadas a la pared; la holgura
se resta (macho) o se suma (hembra) para que encajen sin macho de roscar.

## Parametros clave

| Parametro | Significado |
|-----------|-------------|
| Estandar de Rosca del Aireador | M22 o M24 |
| Direccion de Rosca de la Carcasa | tapa hembra o espiga macho |
| Holgura de Ajuste de Rosca | holgura por lado en roscas impresas (0.1–0.7 mm) |
| Espesor de Pared | pared alrededor del barreno / cavidad |
| Altura de la Carcasa | altura total de la carcasa |
| Profundidad de la Cavidad del Cache | profundidad interior (modo vaso) |
| Agarre Moleteado | estrias axiales de agarre |

## Notas de impresion

Imprime las piezas roscadas con el eje vertical sin soportes; las roscas M22/M24
salen limpias con capas de 0.15–0.20 mm. Empieza con 0.35 mm de holgura y reduce para
un ajuste mas firme. Como las nervaduras de rosca son material positivo (no ranuras
cortadas), cada pieza sale de la cama como un solo cuerpo hermetico.
