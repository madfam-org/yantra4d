# Collar Stay

A 3D-printed **the tapered blade that keeps a shirt-collar point crisp** — generated with **CadQuery** (B-Rep). The rigid hard good Fashion
Cabinet's `collar-stay` notion places and bridges to **here** for its geometry.

Part of the **Yantra4D Hyperobjects Commons** (a Fashion Cabinet FC-200 co-created finding).
Official visualizer and configurator: [Yantra4D](https://app.yantra4d.com).

## Modes

| Mode | Part |

## Hyperobject Profile

- **Domain:** wearable
- **CDG interfaces:** Collar-Point Slot (`flange`) and Stay Blade (`snap`) — the flange is the sewn/set
  edge the Fashion Cabinet dimensional handshake couples to.

## Fabrication notes
Built from safe primitives (cylinders, boxes, makeTorus, boolean cuts, light fillets) —
watertight, prints small and rigid. `CERN-OHL-W-2.0`.
