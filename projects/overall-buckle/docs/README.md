# Overall Buckle

A 3D-printed **the sliding buckle-and-button set of dungarees and overalls — the metal overall hardware made printable** — generated with **CadQuery** (B-Rep). The rigid hard good Fashion
Cabinet's `overall-buckle` notion places and bridges to **here** for its geometry.

Part of the **Yantra4D Hyperobjects Commons** (a Fashion Cabinet FC-200 co-created finding).
Official visualizer and configurator: [Yantra4D](https://app.yantra4d.com).

## Modes

| Mode | Part |
| :--- | :--- |
| **Buckle + Button** | `set` |
| **Buckle** | `buckle` |
| **Bib Button** | `button` |

## Hyperobject Profile

- **Domain:** wearable
- **CDG interfaces:** Strap Slot (`flange`) and Button Catch (`snap`) — the flange is the sewn/set
  edge the Fashion Cabinet dimensional handshake couples to.

## Fabrication notes

Built from safe primitives (cylinders, boxes, boolean cuts, light fillets) — watertight,
prints small and rigid. `CERN-OHL-W-2.0`.
