# 4D Docs — the end-user documentation site

Astro + [Starlight](https://starlight.astro.build) source for the Yantra4D
user-facing docs. This is the **product** documentation a visitor reads; the
platform/architecture documentation for contributors lives in
[`docs/`](../../docs/) at the repo root, and the agent operating contract is
[`AGENTS.md`](../../AGENTS.md).

> **Not deployed yet.** `docs.yantra4d.com` does not resolve — the site build,
> ingress and DNS record are still outstanding. The source below is complete and
> readable in-repo, and `README.md` links point at the source files until the
> site is live. No CI job builds this app, so a change here is checked by review
> rather than by a lane.

```bash
npm install
npm run dev       # Starlight dev server on http://localhost:4321
npm run build     # Static build to ./dist/
npm run preview   # Preview the build
```

## Where pages live

Every `.md` / `.mdx` file under `src/content/docs/` becomes a route named after
its path. The sidebar is **autogenerated per directory** in `astro.config.mjs`,
so adding a page is adding a file — there is no index to update:

| Directory | Sidebar group | Contents |
| :-- | :-- | :-- |
| `src/content/docs/overview/` | Overview | What Yantra4D is, getting started |
| `src/content/docs/platform/` | Platform | Studio, exporting, configuring models, the AI assistant |
| `src/content/docs/commons/` | Hyperobjects Commons | The commons model, manifest specs, the poly-kernel |
| `src/content/docs/developer/` | Developer API | API quickstart, the CLI, creating projects, `llms.txt` |

Images go in `src/assets/` and are embedded with a relative link; favicons and
other static files go in `public/`.

## Keeping it true

These pages describe shipped behaviour to people who cannot read the code, so
they are the surface where a stale claim does the most damage. When a change
moves one of these, the page moves with it:

- **Tier names.** The ladder is `guest | essentials | pro | premium`.
  `madfam` is a permanent *alias*, never a name to print in user-facing copy
  (ADR-006 D4) — see [`docs/AUTH.md`](../../docs/AUTH.md).
- **Where a render runs.** The browser is the default placement and the server
  is the metered exception, chosen by an 11-rule precedence table — see
  [`docs/guides/wasm-mode.md`](../../docs/guides/wasm-mode.md).
- **Export formats and their tiers.** Gated at generation *and* at retrieval —
  see [`docs/reference/openapi.yaml`](../../docs/reference/openapi.yaml).
