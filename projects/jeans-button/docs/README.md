# Jeans Tack Button

A 3D-printed **the no-sew tack button of jeans and workwear — the metal jeans button made printable** — generated with **CadQuery** (B-Rep). The rigid hard good Fashion
Cabinet's `jeans-button` notion places and bridges to **here** for its geometry.

Part of the **Yantra4D Hyperobjects Commons** (a Fashion Cabinet FC-200 co-created finding).
Official visualizer and configurator: [Yantra4D](https://app.yantra4d.com).

## Modes

| Mode | Part |
| :--- | :--- |
| **Button + Tack** | `set` |
| **Button** | `button` |
| **Tack** | `tack` |

## Hyperobject Profile

- **Domain:** wearable
- **CDG interfaces:** Set Face (through the waistband) (`flange`) and Tack Bore (`snap`) — the flange is the sewn/set
  edge the Fashion Cabinet dimensional handshake couples to.

## Fabrication notes

Built from safe primitives (cylinders, boxes, boolean cuts, light fillets) — watertight,
prints small and rigid. `CERN-OHL-W-2.0`.
