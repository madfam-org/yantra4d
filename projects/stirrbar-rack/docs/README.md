# Magnetic Stir Bar Rack

A storage and retrieval hyperobject for PTFE magnetic stir bars, sized to the standard length set.

## Parts / Modos

| Mode | Part | What it is |
|------|------|------------|
| `slot_rack` | Linear Slot Rack | Block of parallel open-top troughs, each length-matched to a standard stir bar, with a finger scoop. |
| `carousel_rack` | Radial Carousel Rack | Round rack with radial open-top slots of graded lengths around a solid grip knob. |
| `magnet_wand` | Magnetic Retriever Wand | Fluted hand wand with a tip pocket for a cylinder magnet to fish out stir bars. |

## Standards & dimensions

- **Stir-bar lengths:** 12 / 20 / 25 / 38 / 50 mm (common PTFE octagonal set).
- **Stir-bar diameter:** ~8 mm typical (range 3–10.5 mm).
- **Slot clearance:** +1.6 mm on width around the PTFE body.
- **Retriever magnet:** cylindrical NdFeB, Ø6–16 mm (Ø10 mm default).

## Parameters

- `bar_diameter` (3–10.5 mm) — stir-bar body diameter.
- `slot_count` (2–8) — number of slots.
- `max_bar_length` (15–50 mm) — caps the graded slot lengths.
- `magnet_diameter` (6–16 mm) — retriever tip magnet.

## Printing notes / Notas de impresión

**EN:** Print racks flat, slots up, no supports. Print the wand upright with the magnet pocket facing down (bridged at the top). Keep the wand in non-magnetic PLA/PETG so only the tip magnet interacts with the bars.

**ES:** Imprime las gradillas planas, con las ranuras hacia arriba, sin soportes. Imprime la varilla en vertical con el alojamiento del imán hacia abajo. Usa PLA/PETG no magnético para que solo el imán de la punta interactúe con las barras.
